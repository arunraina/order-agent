Paste a distributor's unstructured order. Every line still needs a human decision below — nothing is written until you confirm.

Live Stock (Manual Tier)

The only genuinely live data in this catalogue — everything else (price, HSN, GST) is static sample data. Editing a value here writes to data/stock-overrides.json immediately and every match/approval check reflects it right away.

External API

Same pipeline, same governance (propose, never auto-write), reachable by another system — e.g. a distributor's own dispatch tool or a future ERP adapter. Requires an x-api-key header.

GET  /api/v1/health
GET  /api/v1/catalogue
GET  /api/v1/stock
POST /api/v1/stock  { sku_code, qty }
POST /api/v1/process  { orderText }
POST /api/v1/confirm  { orderText, results, decisions }

Example:

curl -X POST http://localhost:3500/api/v1/process \
  -H "x-api-key: <ORDER_AGENT_API_KEY from your .env>" \
  -H "Content-Type: application/json" \
  -d '{"orderText":"ambuja opc 43 ke 150 bora"}'

Set ORDER_AGENT_API_KEY in .env to your own value — without it, the server falls back to a printed dev key (check the terminal running node server.js).
